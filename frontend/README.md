# Frontend

React 19 + Vite + TypeScript SPA — flight map, airport load board, and reroute advisor.

Requires **Node 18+**. Uses npm (a `bun.lock` is also present if you prefer bun).

## First-time setup

```bash
npm install
```

## Run the dev server

```bash
npm run dev
```

App at `http://localhost:5173` (falls back to 5174 if 5173 is taken).

The backend must be running on `http://localhost:8000` — see `backend/README.md`.

## Other commands

```bash
npm run build   # production build → dist/
npm run lint    # eslint
```
