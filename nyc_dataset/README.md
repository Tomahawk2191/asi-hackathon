# NYC-Area Flight Dataset — 5 Days

A filtered subset of the hackathon route data covering the New York City area
(JFK, LGA, EWR + metro relievers), across 5 days chosen for the heaviest
JFK/LGA/EWR traffic and seasonal spread.

**Total: 8,895 NYC-area flights (7,211 touching the big three).**

## How the set is defined

- **NYC airport set** — core `KJFK, KLGA, KEWR` plus metro relievers
  `KTEB, KHPN, KISP, KSWF, KFRG, KCDW, KMMU, KBDR, KLDJ`.
- **Filter** — a flight is included if its **origin OR destination** is in that
  set, so each file holds both departures and arrivals (~890 each per day).
- **Schema preserved** — each file keeps the original
  `asked_at` / `window_start` / `window_end` / `flights` shape (plus an
  `nyc_filter` note), so it is drop-in compatible with the analysis scripts.

## Caveats

1. **"Full day" = 18 h, not 24 h.** Each window runs ~noon → 6am EDT, capturing
   the afternoon/evening/redeye banks but missing the early-morning departure
   push. No single snapshot is a literal calendar day. The only back-to-back
   snapshots in the bundle are **2025-08-21 + 2025-08-22**, which can be stitched
   for ~2 continuous days if 24 h+ continuity is needed.
2. **Overflights excluded.** This is endpoint-based (airport traffic). Flights
   that merely transit NYC airspace without landing or departing there are not
   included — they matter for sector demand but not for "airport" data.
